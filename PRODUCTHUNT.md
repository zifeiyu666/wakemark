### Full product description (About)

WakeMark is for people who bookmark on X and never find the post again.

Your saves land in one endless feed. The official API only returns the newest ~20. Older bookmarks stay trapped on x.com. WakeMark pulls the full history through the Chrome extension (your logged-in session, not a second password), tags each post by topic, and keeps the library searchable.

What you can do:

- Import full bookmark history from the extension popup (duplicates are skipped)
- Search by text, author, summary, or tags
- Ask AI about what you’ve saved; answers cite the original posts
- Use a Chrome side panel so chat stays open while you browse
- Get a scheduled email digest instead of another unread pile
- Export to Notion, or use bookmarks from Cursor / Claude via MCP
- Connect X with official read-only OAuth — we never post for you

Pricing: 7-day trial, no card required. Early plans start at $59/year and that rate stays locked while you remain subscribed.

Website: https://wakemark.app

Hey Product Hunt 👋

I built WakeMark because I kept lying to myself.

I'd bookmark something on X thinking "I'll read this later." Thousands of saves later, I almost never did. I'd remember *someone* wrote a great thread about a topic — then spend ten minutes scrolling my bookmarks, give up, and Google it like the save never happened. Embarrassing, but true.

So I made the tool I wished existed:

- **Actually find things** — auto-tags, search, Ask AI that cites the original tweets (not vibes).
- **MCP** — connect Cursor, Claude, ChatGPT, or VS Code with one API key. Your agents can search and pull from your bookmarks where you already work.
- **Digest** — a gentle nudge to revisit what you saved, instead of letting it rot.

If you're on Chrome: install the extension → sign in → **Import history** in the popup → allow x.com when Chrome asks → keep that tab open until scrolling stops. Then try to find something you *know* you saved months ago. That's the moment it clicks.

7-day trial, no credit card: https://wakemark.app

Would genuinely love your feedback — especially if import stalls, search misses something obvious, or Ask AI cites the wrong post. That's the stuff that keeps me up at night.

## Launch-day replies (short)

**Pricing**
7-day trial, no card. After that, early annual plans start at $59 and that price is locked while you stay subscribed.

**vs Raindrop / Readwise / Notion**
Those tools store links well. WakeMark is built around X bookmarks: full-history import (API only gives ~20), auto-tags, Ask AI with citations, and a digest. Notion export is there if you still want a database.

**Privacy / X password**
We never ask for your X password. Dashboard sync uses official read-only OAuth. History import runs in your browser on x.com/i/bookmarks after you click Import history and grant access.

**Does it post on my account?**
No. Read-only bookmarks. We don’t tweet for you.

**Free?**
Trial is 7 days. After that it’s a paid plan — one product, full access.
